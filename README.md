# Paradigmas de Linguagens de Programação: Aula 00

Atividade introdutória usando Python.

## Objetivos

- Executar um programa simples;
- Trabalhar com entrada, saída e repetição;
- Identificar o paradigma usado nos exemplos.

## Estrutura


## 1. Olá, mundo!

```python
print("Olá, mundo!")
```

## 2. Tabuada

O programa recebe um número e usa um `for` para mostrar a tabuada de 1 a 10.

## 3. Paradigma

Os exemplos usam principalmente o paradigma **imperativo/procedural**, porque o programa descreve uma sequência de instruções.

Python também é uma linguagem multiparadigma e possui recursos de orientação a objetos e programação funcional.

## 4. Execução

```bash
python3 src/ola_mundo.py
python3 src/tabuada.py
```
